# Starbucks Ritual

Create a modern, elegant, and high-converting E-commerce prototype inspired by the Starbucks brand aesthetic, using its iconic color palette (Starbucks Deep Green #006241, Warm Neutral/Cream #F2F0EB, White #FFFFFF, and Gold accents #D4E9E2 / #CBA258).

Please build the application with the following layout and functional structure:

1. HEADER (Navigation Bar):

   - Left: Include the Starbucks Logo image placeholder.

   - Navigation Links: "Ediciones Limitadas", "Colección", "Exclusivos", "Membresía", and "Referidos".

   - Right Icons:

     * Search icon (magnifying glass).

     * User account/login icon.

     * Shopping cart icon represented as a custom Coffee Cup icon with a item badge counter.

2. HERO SECTION:

   - Top banner promoting "Ediciones Limitadas".

   - Main headline with a compelling experience-focused tagline inviting consumers to buy based on the unique Starbucks ritual and luxury experience.

   - Two CTA buttons side by side: "Explorar Colección" (Primary Green Button) and "Ver Membresía" (Secondary Outlined Button).

   - A large, high-quality, full-width showcase image featuring our exclusive Starbucks collection.

3. MEMBERSHIP SECTION (2-Column Grid Layout):

   - Left Column: Catchy title and copywriting inviting customers to join the exclusive membership, highlighting benefits like access to rare products, free shipping of exclusive coffee tastings, and VIP perks. Includes a prominent CTA button: "Comprar Membresía".

   - Right Column: An immersive visual representation of an inner vault filled with glowing gold-edition Starbucks products (tumblers, golden coffee bags, rare merchandise).

4. INTERACTIVE CATALOG SECTION ("Colección Green" vs "Colección Perú"):

   - Tab/Toggle switch allowing the user to select between "Colección Green" and "Colección Perú".

   - Sub-category filter buttons (pills) under the selected collection: "Vasos térmicos", "Pines", "Kit reutilizable", "Tazas", "Bolsas de café", and "Exclusivo".

   - Product Grid displaying cards with product images, titles, prices, "Exclusive" badges, and an "Add to Cart" button.

5. FOOTER (3 Columns Layout):

   - Column 1 (Left): Title "Starbucks Perú" followed by a short, inspiring brand paragraph about the coffee experience and quality.

   - Column 2 (Center): Quick navigation links mirroring the header options ("Ediciones Limitadas", "Colección", "Exclusivos", "Membresía", "Referidos").

   - Column 3 (Right): Contact details stating "Dirección: Lima, Perú", customer service contact info, and operational hours.

6. FLOATING FEATURES:

   - A sticky, floating WhatsApp widget button fixed at the bottom right corner of the screen across all pages for direct support.

Ensure clean typography, modern rounded UI elements, subtle hover animations, and a responsive mobile-friendly layout.
